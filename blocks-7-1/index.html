Will my block break?break?

In WordPress 7.1 the post editor canvas is always an iframe, on every theme, no matter what apiVersion your block declares. Paste the parts of your block below and find out which lines are about to have a bad day.

Heads up: this is for general testing, not a guaranteed result.

This page reads your code for known patterns. It doesn't run it. Before you ship, test your block in a real WordPress 7.1 environment and make sure it works. Seriously. Do it.
