# Spacefast demos

Small, self-contained demo pages, each published to its own [Spacefast](https://spacefast.com) Space on the **Ryan - DevRel** team. Each folder is one site.

| Folder | Live site | What it is |
|---|---|---|
| [`blocks-7-1/`](blocks-7-1/) | https://are-my-blocks-borked-in-7-1.space.fast/ | Will My Block Break? A WordPress 7.1 block tester. |
| [`wp-kses-tester/`](wp-kses-tester/) | https://wp-kses-new-parser-tester.space.fast/ | Paste HTML and compare the legacy and new `wp_kses()` parsers, using WordPress nightly in your browser. |
